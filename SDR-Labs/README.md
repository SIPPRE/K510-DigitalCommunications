# Ψηφιακές Επικοινωνίες (ECE_K510) — Υλικό εργαστηρίου φοιτητών

Φυλλάδια και flowgraphs **GNU Radio** για τα εργαστήρια του μαθήματος. Χρησιμοποιείτε
**GNU Radio 3.10** και ένα **RTL-SDR** (μόνο λήψη). Η εκπομπή γίνεται μόνο από τον διδάσκοντα.

## Ξεκινήστε από εδώ

1. Εγκατάσταση (Ubuntu, Windows ή macOS): βλ. [`setup/SETUP.md`](setup/SETUP.md) και το
   φυλλάδιο του Εργαστηρίου 0.
2. Ανοίξτε το φυλλάδιο της άσκησης (PDF) και ακολουθήστε το με τα αρχεία `.grc` της ίδιας άσκησης.
